# Expense Tracker

Шаблон трекера витрат для курсу React v4: модулі 5–8, Next.js.

## Як почати

1. Натисни «Use this template» → «Create a new repository» і назви репозиторій `expense-tracker`.
2. Склонуй свій репозиторій і запусти проєкт:

```bash
git clone https://github.com/<твій-логін>/expense-tracker.git
cd expense-tracker
npm install
npm run dev
```

Застосунок відкривається за адресою http://localhost:3000.

## Код уроків

Код трекера після кожного уроку лежить у репозиторії курсу [goitacademy/react-v4-expense-tracker](https://github.com/goitacademy/react-v4-expense-tracker): тег `m5-03` — стан після уроку 3 модуля 5, `m5-04` — після уроку 4 і так далі.
